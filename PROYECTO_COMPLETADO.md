## 📊 Conceptos Cubiertos

### Strings
- `split()` - Dividir en caracteres
- `reverse()` - Invertir arreglo
- `join()` - Combinar caracteres
- `includes()` - Verificar contenencia
- `replace()` - Reemplazar caracteres
- `toLowerCase()` - Convertir a minúsculas

### Arreglos
- `push()` - Agregar elementos
- `filter()` - Filtrar elementos
- `sort()` - Ordenar
- `Math.max()` - Encontrar máximo
- Spread operator `...` - Desempaquetar

### Operadores
- `+` - Suma
- `%` - Módulo (resto)
- `>`, `<`, `===` - Comparación
- `!==`, `===` - Igualdad

### Lógica
- Bucles `for`, `for...of`
- Condicionales `if/else`
- Funciones arrow
- Comparadores personalizados
