## 🚀 Cómo Empezar

1. **Abre la aplicación** en tu navegador
2. **Selecciona un ejercicio** (recomendado empezar por Básico)
3. **Edita el archivo** correspondiente en `src/exercises/`
4. **Haz clic en "Run tests"** para verificar
5. **Lee la guía** si necesitas ayuda

## 📊 Resumen de Conceptos

### Strings
- **ex2:** Invertir cadenas (`split`, `reverse`, `join`)
- **ex5:** Contar caracteres específicos (`includes`, bucles)
- **ex7:** Normalizar y comparar (`replace`, `toLowerCase`)

### Arreglos
- **ex4:** Desempaquetar arreglos (spread operator `...`)
- **ex6:** Encontrar máximo (`Math.max`, comparación)
- **ex8:** Ordenar valores (`sort`, comparadores)
- **ex9:** Filtrar elementos (`filter`, condiciones)

### Matemática & Lógica
- **ex1:** Operaciones básicas (`+`)
- **ex3:** Secuencias (`Fibonacci`, iteración)
- **ex9:** Módulo (`%`, divisibilidad)
