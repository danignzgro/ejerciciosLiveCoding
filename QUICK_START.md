## 📝 Contenido de las Guías

Cada guía incluye:

✅ **Explicación del problema** - Qué debe hacer la función

✅ **Comparativas** - Ventajas/desventajas de cada estrategia

## 🔄 Flujo de Usuario

```
1. Usuario abre la página
   ↓
2. Ve ejercicios organizados por dificultad
   ↓
3. Lee descripción del ejercicio
   ↓
4. Abre el archivo exN.ts en su editor
   ↓
5. Implementa la solución
   ↓
6. Haz clic en "Run tests"
   ↓
7. Ve resultados en tiempo real
   ↓
8. Si falla, abre GUIA_exN.md
   ↓
9. Lee las estrategias de resolución
   ↓
10. Intenta nuevamente
```

## 🎯 Próximos Pasos

### Usar la Plataforma
1. Ejecuta `npm run dev` para iniciar
2. Abre http://localhost:5173
3. Selecciona un ejercicio
4. ¡Comienza a resolver!

### Extender con Más Ejercicios
1. Crea `exN.ts` y `exN.test.ts`
2. Crea `GUIA_exN.md` detallada
3. Añade a `src/exercises/index.ts`
4. Asigna dificultad (Básico/Intermedio/Avanzado)
